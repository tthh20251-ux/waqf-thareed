# Waqf Thareed

A warm and welcoming landing page for `Waqf Thareed` (وقف ثريد), a charitable foundation serving families in Downtown Amman, Jordan.

## Features
- React + Vite app
- Tailwind CSS styling
- Arabic RTL content
- Responsive landing page sections
- Mission, impact, volunteering, and donation sections

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL displayed in the terminal.

## Build for production

```bash
npm run build
```
